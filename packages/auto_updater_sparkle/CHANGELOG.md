## 1.0.0

* First release as `auto_updater_sparkle`.
* Support Swift Package Manager with Sparkle 2.10.1 or later.
* Require Flutter 3.50, Dart 3.14, and macOS 12 or later.
* Report Sparkle startup errors to callers of `setFeedURL`.
* Include HTTP status or the underlying native error in update failures.
